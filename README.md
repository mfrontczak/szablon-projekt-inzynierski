# Szablon dla Projektu Inżynierskiego 
## Struktura plików
Poniżej przedstawiono standardową strukturę katalogów obowiązującą w projekcie. Została ona zaprojektowana w sposób modułowy, co pozwala na jej skalowanie wraz z rozwojem systemu.

* `docs/`: Dokumentacja projektowa, techniczna oraz wdrożeniowa.

* `reports/`: Repozytorium raportów generowanych w trakcie cyklu życia projektu.

* `src/`: Główny katalog zawierający kod źródłowy aplikacji, uporządkowany zgodnie z przyjętymi wzorcami projektowymi.

**Uwaga:** Powyższy układ stanowi fundament projektu. Dopuszcza się wprowadzanie dodatkowych podkatalogów (np. `tests/`, `scripts/`, `assets/`) w zależności od specyfiki i wymagań rozwijanego modułu.
